# Mejoras futuras (plan)

> Documento interno. No difundir. Estos cambios se implementarán a futuro, cuando se valide el producto con clientes reales.

## Modelo de negocio: Freemium B2B (Camino A)

- La app es **gratis** para las empresas: impulsa adopción y crecimiento (modelo tipo Facebook/Meta: gratis para crecer, monetización después).
- Los inversores financian el crecimiento; necesitamos un plan documentado de cómo monetizaremos al alcanzar masa crítica.
- Prohibido: cobrar desde el inicio a las empresas que usen la base gratuita.

## Road map Pro (funciones de pago a futuro)

| Gratis | Pro (pago futuro) |
|---|---|
| Chat IA + notas | Reportes avanzados / exportación PDF |
| Panel de líderes | Analítica de tendencias por equipo |
| Límite de empleados | Alertas automáticas de riesgo |
| Límite de conversaciones | Integraciones (Slack, Excel) |

Regla del modelo: lo gratis debe resolver el problema real (engagement), lo pro debe *mejorar* lo que ya se usa — no bloquear lo esencial.
